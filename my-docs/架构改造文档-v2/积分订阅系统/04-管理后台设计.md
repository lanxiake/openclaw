# Admin Console 积分订阅管理设计文档

> 最后更新：2026-02-25

## 1. 概述

Admin Console 提供积分系统和订阅系统的完整管理功能，分为两大模块：**积分管理**和**订阅管理**。

## 2. 积分管理模块

### 2.1 页面结构

```
积分管理
├── 积分概览（CreditsPage）
│   ├── 系统积分统计
│   ├── 用户积分列表
│   └── 积分包管理
├── 模型定价管理（PricingPage）
│   ├── 模型提供商列表
│   ├── 模型定价配置
│   └── 倍率管理
└── 用户积分详情（UserCreditsPage）
    ├── 用户积分余额
    ├── 积分批次明细
    ├── 积分流水记录
    └── 手动发放积分
```

### 2.2 积分概览（CreditsPage）

#### 系统统计卡片

| 指标         | 说明                         |
| ------------ | ---------------------------- |
| 总用户数     | 有积分账户的用户总数         |
| 总积分余额   | 系统中所有用户的积分余额之和 |
| 本月发放积分 | 当月各来源发放的积分总量     |
| 本月消费积分 | 当月消费的积分总量           |
| 本月过期积分 | 当月过期清零的积分总量       |

#### 用户积分列表

| 列       | 说明                |
| -------- | ------------------- |
| 用户     | 显示名称 + 手机号   |
| 当前余额 | 可用积分            |
| 累计获得 | 历史总获得          |
| 累计消费 | 历史总消费          |
| 累计过期 | 历史总过期          |
| 操作     | 查看详情 / 手动发放 |

支持按用户搜索和排序。

#### 积分包管理

| 操作           | 说明                                       |
| -------------- | ------------------------------------------ |
| 查看积分包列表 | 代码、名称、价格、积分数、有效期、推荐状态 |
| 编辑积分包     | 修改定价、积分数量                         |
| 设置推荐       | 选择推荐展示的积分包                       |
| 购买统计       | 各包的购买次数、总收入                     |
| 购买记录       | 按时间/用户/积分包类型查看                 |

> **页面位置**：`apps/admin-console/src/pages/credits/CreditsPage.tsx`

### 2.3 模型定价管理（PricingPage）

#### 功能描述

管理员配置各大模型的积分消耗规则。

#### 操作流程

```
1. 页面加载时自动获取已录入的模型提供商列表
2. 管理员从下拉列表中选择模型提供商
3. 加载该提供商下的模型列表
4. 管理员选择具体模型
5. 设置 input token 积分单价（每百万 tokens）
6. 设置 output token 积分单价（每百万 tokens）
7. 设置倍率（multiplier）
8. 保存
```

#### 定价列表

| 列          | 说明                                     |
| ----------- | ---------------------------------------- |
| 模型名称    | 显示名称                                 |
| 模型标识    | model_id（如 anthropic/claude-sonnet-4） |
| Input 单价  | 每百万 input tokens 积分消耗             |
| Output 单价 | 每百万 output tokens 积分消耗            |
| 倍率        | 当前倍率值                               |
| 状态        | 激活/禁用                                |
| 操作        | 编辑 / 删除 / 切换状态                   |

#### 倍率说明

倍率是一个便于管理员快速调整 token 与积分比例的乘数：

- `1.00`：标准定价
- `0.50`：半价促销
- `2.00`：双倍消耗
- 支持精度：numeric(5,2)，范围 0.01 ~ 999.99

> **页面位置**：`apps/admin-console/src/pages/credits/PricingPage.tsx`

### 2.4 用户积分详情（UserCreditsPage）

#### 功能

| 功能     | 说明                                        |
| -------- | ------------------------------------------- |
| 余额概览 | 当前余额、累计获得/消费/过期                |
| 批次列表 | 有效批次、来源、剩余积分、过期时间          |
| 流水记录 | 按时间倒序展示所有流水，支持按类型/来源过滤 |
| 手动发放 | 管理员输入积分数和过期月数，备注原因        |

#### 手动发放表单

| 字段     | 类型   | 必填 | 说明                 |
| -------- | ------ | ---- | -------------------- |
| 积分数   | number | 是   | 要发放的积分数量     |
| 过期月数 | number | 是   | 有效期（月），默认 3 |
| 备注     | text   | 否   | 发放原因             |

> **页面位置**：`apps/admin-console/src/pages/credits/UserCreditsPage.tsx`

## 3. 订阅管理模块

### 3.1 页面结构

```
订阅管理
├── 套餐管理（PlansPage）
│   └── 查看内置套餐（免费/月付/年付）
├── 订阅列表（SubscriptionsPage）
│   ├── 订阅列表（过滤/分页）
│   ├── 订阅统计
│   ├── 管理员取消订阅
│   └── 延长订阅
└── 订单管理（OrdersPage）
    ├── 支付订单列表
    ├── 订单详情
    └── 退款处理
```

### 3.2 套餐管理（PlansPage）

展示系统内置的三种订阅计划（只读）：

| 套餐   | 代码    | 月价  | 年价   | 每月积分 | 状态 |
| ------ | ------- | ----- | ------ | -------- | ---- |
| 免费版 | free    | 0 元  | 0 元   | 0        | 激活 |
| 月付版 | monthly | 30 元 | —      | 2000     | 激活 |
| 年付版 | yearly  | —     | 300 元 | 2000     | 激活 |

**说明**：订阅计划在初始化脚本中创建，管理员可查看但不建议修改（因为会影响现有订阅用户）。

> **页面位置**：`apps/admin-console/src/pages/subscriptions/PlansPage.tsx`
>
> **初始化脚本**：`scripts/seed-dev.ts` - `seedPlans()`

### 3.3 订阅列表（SubscriptionsPage）

#### 统计卡片

| 指标       | 说明                     |
| ---------- | ------------------------ |
| 活跃订阅数 | 状态为 active 的订阅总数 |
| 月付用户   | 月付活跃订阅数           |
| 年付用户   | 年付活跃订阅数           |
| 本月新增   | 当月新创建的订阅数       |
| 本月取消   | 当月取消的订阅数         |

#### 订阅列表

| 列       | 说明                             |
| -------- | -------------------------------- |
| 用户     | 显示名称 + 手机号                |
| 套餐     | 免费版/月付版/年付版             |
| 计费周期 | monthly/yearly                   |
| 状态     | active/canceled/expired/past_due |
| 当前周期 | 开始时间 ~ 结束时间              |
| 首月标记 | 是否首月优惠                     |
| 创建时间 | 订阅创建时间                     |
| 操作     | 查看详情 / 取消 / 延长           |

支持过滤条件：

- 状态过滤：全部 / 活跃 / 已取消 / 已过期
- 套餐过滤：全部 / 月付 / 年付
- 日期范围

#### 管理员操作

**取消订阅**：

| 字段     | 类型  | 必填 | 说明                    |
| -------- | ----- | ---- | ----------------------- |
| 取消方式 | radio | 是   | 立即取消 / 周期结束取消 |
| 取消原因 | text  | 否   | 管理员备注              |

**延长订阅**：

| 字段     | 类型   | 必填 | 说明               |
| -------- | ------ | ---- | ------------------ |
| 延长天数 | number | 是   | 延长当前周期的天数 |

> **页面位置**：`apps/admin-console/src/pages/subscriptions/SubscriptionsPage.tsx`

### 3.4 订单管理（OrdersPage）

#### 订单列表

| 列       | 说明                                  |
| -------- | ------------------------------------- |

支持过滤条件：

- 订单类型
- 支付状态
- 支付方式
- 日期范围

#### 退款操作

| 字段     | 类型   | 必填 | 说明                   |
| -------- | ------ | ---- | ---------------------- |

> **页面位置**：`apps/admin-console/src/pages/subscriptions/OrdersPage.tsx`

## 4. 权限控制

### 4.1 管理员角色

| 角色        | 积分管理        | 订阅管理         | 说明       |
| ----------- | --------------- | ---------------- | ---------- |
| super_admin | 全部权限        | 全部权限         | 超级管理员 |
| operator    | 查看 + 手动发放 | 查看 + 取消/延长 | 运营人员   |

### 4.2 用户端限制

用户**不可以**自行执行以下操作：

- 修改订阅计划
- 取消订阅
- 修改模型定价
- 手动发放积分

用户**可以**执行：

- 查看自己的积分余额和流水
- 购买积分包
- 购买/续费订阅

## 5. 类型定义

### 5.1 Admin Console 积分类型

```typescript
// apps/admin-console/src/types/credits.ts

interface CreditAccountSummary {
  userId: string;
  displayName: string;
  phone: string;
  totalBalance: number;
  totalEarned: number;
  totalConsumed: number;
  totalExpired: number;
}

interface CreditPackConfig {
  code: string;
  name: string;
  price: number; // 价格（分）
  credits: number; // 积分数
  expiryMonths: number; // 有效期（月）
  recommended: boolean; // 是否推荐
  sortOrder: number; // 排序
  isActive: boolean; // 是否可购买
}

interface CreditPackStats {
  packCode: string;
  packName: string;
  totalOrders: number; // 总购买次数
  totalRevenue: number; // 总收入（分）
  totalCredits: number; // 总发放积分
}
```

### 5.2 Admin Console 订阅类型

```typescript
// apps/admin-console/src/types/subscription.ts

interface SubscriptionSummary {
  id: string;
  userId: string;
  userName: string;
  userPhone: string;
  planCode: string;
  planName: string;
  status: string;
  billingCycle: string;
  isFirstMonth: boolean;
  currentPeriodStart: string;
  currentPeriodEnd: string;
  creditsPerPeriod: number;
  createdAt: string;
}

interface SubscriptionStats {
  totalActive: number;
  monthlyCount: number;
  yearlyCount: number;
  newThisMonth: number;
  canceledThisMonth: number;
}
```

> **类型位置**：
>
> - `apps/admin-console/src/types/credits.ts`
> - `apps/admin-console/src/types/subscription.ts`
