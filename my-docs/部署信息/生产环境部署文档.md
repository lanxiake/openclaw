## 前置要求

### 服务器要求

- **操作系统**: OpenCloudOS 9.4（当前生产环境）/ CentOS Stream 9 / RHEL 9 兼容发行版
- **CPU**: 4 核心或以上
- **内存**: 8GB 或以上（推荐 16GB）
- **磁盘**: 100GB 或以上（SSD 推荐）
- **网络**: 公网 IP，开放必要端口

### 软件依赖

- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **Nginx**: 1.20+（用于反向代理）
- **Node.js**: 22+（用于构建和迁移）

### 权限要求

- 具有 `sudo` 权限的用户
- 能够执行 Docker 命令（或加入 `docker` 用户组）

## 部署步骤

### 1. 服务器初始化

#### 1.1 更新系统

```bash
sudo dnf makecache
sudo dnf update -y
```

#### 1.2 安装 Docker 和 Docker Compose

```bash
# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 将当前用户添加到 docker 组
sudo usermod -aG docker $USER
newgrp docker
```

#### 1.3 安装 Nginx

```bash
sudo dnf install -y nginx
sudo systemctl enable --now nginx
```

#### 1.4 创建部署目录

```bash
# 创建项目目录
sudo mkdir -p /opt/mtbot
sudo chown $USER:$USER /opt/mtbot
cd /opt/mtbot

# 创建必要的子目录
mkdir -p {logs,data,config,init}
```

### 2. 部署基础设施

#### 2.1 复制配置文件

将以下文件复制到 `/opt/mtbot`：

- `docker-compose.infra.yml`
- `.env.infra`（从 `.env.infra.example` 创建）

#### 2.2 配置环境变量

```bash
cd /opt/mtbot
cp .env.infra.example .env.infra
nano .env.infra  # 编辑并修改密码和配置
```

**重要**: 生产环境必须修改所有默认密码！

#### 2.3 启动基础设施服务

```bash
# 启动核心服务（PostgreSQL + Redis + MinIO）
docker-compose -f docker-compose.infra.yml --profile minimal up -d

# 或启动所有基础设施服务
docker-compose -f docker-compose.infra.yml up -d
```

#### 2.4 验证基础设施

```bash
# 检查服务状态
docker-compose -f docker-compose.infra.yml ps

# 检查 PostgreSQL
docker-compose -f docker-compose.infra.yml exec postgres pg_isready -U mtbot_admin

# 检查 Redis
docker-compose -f docker-compose.infra.yml exec redis redis-cli -a "YOUR_REDIS_PASSWORD" ping

# 检查 MinIO
curl http://localhost:22004
```

### 3. 数据库初始化

#### 3.1 执行数据库迁移

```bash
# 设置数据库连接
export DATABASE_URL="postgresql://mtbot_admin:YOUR_PASSWORD@localhost:22001/mtbot_prod"

# 执行迁移
cd /opt/mtbot
pnpm db:migrate
```

#### 3.2 创建初始管理员账户（可选）

```bash
# 使用脚本创建管理员
pnpm create-admin
```

### 4. 部署应用服务

#### 4.1 构建应用镜像

```bash
cd /opt/mtbot

# 构建 Gateway 镜像
docker build -t mtbot-gateway:latest -f Dockerfile .

# 构建 API Server 镜像
docker build -t mtbot-api-server:latest -f apps/api-server/Dockerfile --target production .
```

#### 4.2 配置生产环境变量

```bash
cd /opt/mtbot
cp .env.production.example .env.production
nano .env.production  # 编辑并配置所有环境变量
```

#### 4.3 启动应用服务

```bash
# 启动所有应用服务
docker-compose -f docker-compose.prod.yml up -d

# 查看服务状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f
```

### 5. 部署前端应用

#### 5.1 构建 Admin Console

```bash
cd /opt/mtbot/apps/admin-console

# 安装依赖
pnpm install

# 配置环境变量
cat > .env.production << EOF
VITE_API_BASE_URL=http://localhost:22300/api
VITE_WS_URL=ws://localhost:22189
EOF

# 构建
pnpm build
```

#### 5.2 配置 Nginx

将 `nginx.conf` 复制到 `/etc/nginx/conf.d/mtbot.conf`：

```bash
sudo cp nginx.conf /etc/nginx/conf.d/mtbot.conf
sudo nginx -t  # 测试配置
sudo systemctl reload nginx
```

#### 5.3 部署静态文件

```bash
# 创建网站目录
sudo mkdir -p /var/www/mtbot-website
sudo mkdir -p /var/www/mtbot-admin

# 部署 Website
sudo cp -r apps/website/* /var/www/mtbot-website/

# 部署 Admin Console
sudo cp -r apps/admin-console/dist/* /var/www/mtbot-admin/

# 设置权限
sudo chown -R nginx:nginx /var/www/mtbot-website
sudo chown -R nginx:nginx /var/www/mtbot-admin
```

#### 5.4 复制 SSL 证书

```bash
# 复制证书文件到服务器
sudo mkdir -p /opt/mtbot/mtbot.top_nginx
sudo cp -r mtbot.top_nginx/* /opt/mtbot/mtbot.top_nginx/

# 设置证书权限（确保私钥安全）
sudo chmod 600 /opt/mtbot/mtbot.top_nginx/*.key
sudo chmod 644 /opt/mtbot/mtbot.top_nginx/*.crt
```

### 6. 配置 SSL/TLS（可选但推荐）

```bash
# 使用 Certbot 安装 Let's Encrypt 证书
sudo dnf install -y epel-release
sudo dnf install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
```

## 服务配置

### Gateway 配置

Gateway 服务的主要配置通过环境变量和配置文件管理：

**环境变量**:

- `MTBOT_GATEWAY_TOKEN`: Gateway 认证令牌（必需）
- `MTBOT_GATEWAY_PORT`: Gateway 端口（默认 22189）
- `DATABASE_URL`: 数据库连接字符串
- `REDIS_HOST`, `REDIS_PORT`, `REDIS_PASSWORD`: Redis 连接信息

**配置文件**: `~/.mtbot/mtbot.json`

### API Server 配置

API Server 通过环境变量配置：

- `API_SERVER_PORT`: 服务端口（默认 3000）
- `API_SERVER_HOST`: 绑定地址（默认 0.0.0.0）
- `DATABASE_URL`: 数据库连接字符串
- `JWT_SECRET`: JWT 密钥（必需）
- `CORS_ORIGINS`: 允许的 CORS 来源（逗号分隔）

### Admin Console 配置

通过构建时环境变量配置：

- `VITE_API_BASE_URL`: API 服务地址
- `VITE_WS_URL`: WebSocket 服务地址

## 数据库初始化

### 自动初始化

PostgreSQL 容器启动时会自动执行 `/docker-entrypoint-initdb.d/` 目录下的 SQL 脚本。

初始化脚本位置: `docker-init/postgres/01-init.sql`

### 手动初始化

如果需要在已有数据库上初始化：

```bash
# 连接到数据库
docker-compose -f docker-compose.infra.yml exec postgres psql -U mtbot_admin -d mtbot_prod

# 执行初始化脚本
\i /docker-entrypoint-initdb.d/01-init.sql
```

### 数据库迁移

使用 Drizzle ORM 进行数据库迁移：

```bash
# 生成迁移文件（开发环境）
pnpm db:generate

# 执行迁移（生产环境）
DATABASE_URL="postgresql://..." pnpm db:migrate
```

## Nginx 配置

### 配置文件位置

- 配置文件: `/etc/nginx/conf.d/mtbot.conf`
- 主配置: `/etc/nginx/nginx.conf`
- SSL 证书: `/opt/mtbot/mtbot.top_nginx/`（从部署信息目录复制）

### 配置说明

参考 [Nginx 配置示例](nginx.conf.example)

主要配置：

- Website: `http://your-domain/` 或端口 `22888`
- Admin Console: `http://your-domain/admin` 或端口 `22176`
- API Server: `http://your-domain/api` 或端口 `22300`
- Gateway: WebSocket 代理到 `ws://localhost:22189`

### 重新加载配置

```bash
sudo nginx -t  # 测试配置
sudo systemctl reload nginx  # 重新加载
```

## 服务管理

### 启动服务

```bash
# 启动基础设施
docker-compose -f docker-compose.infra.yml up -d

# 启动应用服务
docker-compose -f docker-compose.prod.yml up -d
```

### 停止服务

```bash
# 停止应用服务
docker-compose -f docker-compose.prod.yml down

# 停止基础设施（谨慎操作！）
docker-compose -f docker-compose.infra.yml down
```

### 重启服务

```bash
# 重启单个服务
docker-compose -f docker-compose.prod.yml restart api-server

# 重启所有服务
docker-compose -f docker-compose.prod.yml restart
```

### 查看日志

```bash
# 查看所有服务日志
docker-compose -f docker-compose.prod.yml logs -f

# 查看单个服务日志
docker-compose -f docker-compose.prod.yml logs -f api-server

# 查看最近 100 行日志
docker-compose -f docker-compose.prod.yml logs --tail=100 api-server
```

### 健康检查

```bash
# API Server
curl http://localhost:22300/api/health

# Gateway
curl -H "Authorization: Bearer $MTBOT_GATEWAY_TOKEN" http://localhost:22189/health

# PostgreSQL
docker-compose -f docker-compose.infra.yml exec postgres pg_isready

# Redis
docker-compose -f docker-compose.infra.yml exec redis redis-cli ping
```

## 监控与日志

### 日志位置

- **应用日志**: `/opt/mtbot/logs/`
  - `api-server/`: API Server 日志
  - `gateway/`: Gateway 日志

- **Docker 日志**: 使用 `docker-compose logs` 查看

- **Nginx 日志**:
  - 访问日志: `/var/log/nginx/access.log`
  - 错误日志: `/var/log/nginx/error.log`

### 监控组件（可选）

如果启用了监控组件（Prometheus + Grafana）：

```bash
# 启动监控组件
docker-compose -f docker-compose.infra.yml --profile monitoring up -d

# 访问 Grafana
# http://localhost:22012
# 默认用户名: grafana_admin
# 默认密码: 见 .env.infra
```

## 故障排查

### 常见问题

#### 1. 服务无法启动

```bash
# 检查 Docker 服务状态
sudo systemctl status docker

# 检查端口占用
sudo netstat -tulpn | grep <port>

# 查看服务日志
docker-compose -f docker-compose.prod.yml logs <service-name>
```

#### 2. 数据库连接失败

```bash
# 检查 PostgreSQL 是否运行
docker-compose -f docker-compose.infra.yml ps postgres

# 测试数据库连接
docker-compose -f docker-compose.infra.yml exec postgres psql -U mtbot_admin -d mtbot_prod -c "SELECT 1;"

# 检查环境变量
docker-compose -f docker-compose.prod.yml config | grep DATABASE_URL
```

#### 3. Gateway 无法连接

```bash
# 检查 Gateway Token
echo $MTBOT_GATEWAY_TOKEN

# 检查 Gateway 日志
docker-compose -f docker-compose.prod.yml logs gateway

# 测试 Gateway 健康检查
curl -H "Authorization: Bearer $MTBOT_GATEWAY_TOKEN" http://localhost:18789/health
```

#### 4. Nginx 502 错误

```bash
# 检查 Nginx 配置
sudo nginx -t

# 检查后端服务是否运行
curl http://localhost:22300/api/health

# 查看 Nginx 错误日志
sudo tail -f /var/log/nginx/error.log
```

### 调试命令

```bash
# 进入容器调试
docker-compose -f docker-compose.prod.yml exec api-server sh
docker-compose -f docker-compose.prod.yml exec gateway sh

# 查看容器资源使用
docker stats

# 查看网络连接
docker network inspect mtbot-network
```

## 备份与恢复

### 数据库备份

```bash
# 创建备份
docker-compose -f docker-compose.infra.yml exec postgres pg_dump -U mtbot_admin mtbot_prod > backup_$(date +%Y%m%d_%H%M%S).sql

# 压缩备份
gzip backup_*.sql
```

### 数据库恢复

```bash
# 恢复备份
gunzip backup_20260101_120000.sql.gz
docker-compose -f docker-compose.infra.yml exec -T postgres psql -U mtbot_admin mtbot_prod < backup_20260101_120000.sql
```

### 数据卷备份

```bash
# 备份所有数据卷
docker run --rm -v mtbot-postgres-data:/data -v $(pwd):/backup alpine tar czf /backup/postgres-data-backup.tar.gz /data
```

### 自动备份脚本

创建定时任务（crontab）：

```bash
# 编辑 crontab
crontab -e

# 添加每日备份任务（每天凌晨 2 点）
0 2 * * * /opt/mtbot/scripts/backup-db.sh
```

## 安全建议

1. **修改所有默认密码**: 生产环境必须修改所有服务的默认密码
2. **使用强密码**: 密码长度至少 16 位，包含大小写字母、数字和特殊字符
3. **配置防火墙**: 只开放必要的端口
4. **启用 SSL/TLS**: 使用 HTTPS 加密通信
5. **定期更新**: 保持 Docker 镜像和系统软件更新
6. **限制访问**: 使用 Nginx 限制管理界面的访问 IP
7. **日志审计**: 定期检查日志，发现异常访问
