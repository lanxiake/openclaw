## 测试环境准备

### 1. 启动后端服务

```bash
# 启动 PostgreSQL 数据库
docker-compose up -d postgres

# 启动 API Server
pnpm api:dev

# 启动 Gateway（可选，用于测试实时通信）
pnpm gateway:dev
```

### 2. 启动 Windows 客户端

```bash
cd apps/windows
pnpm dev
```

## 后续优化建议

### 1. 使用预签名 URL 优化文件上传

**当前实现**: 文件通过 Base64 编码后通过 WebSocket 传输

**问题**:
- Base64 编码增加 33% 的数据量
- 大文件传输占用 WebSocket 连接
- 内存占用较高

**优化方案**:
1. 客户端请求预签名 URL
2. 直接通过 HTTP PUT 上传到 MinIO
3. 上传完成后通知服务器

**优先级**: 中

### 2. 添加上传断点续传

**当前实现**: 上传失败需要重新上传整个文件

**优化方案**:
- 使用 MinIO 的分片上传 API
- 支持断点续传
- 显示更详细的上传进度

**优先级**: 低

### 3. 添加文件预览功能

**功能描述**:
- 上传前预览图标
- 验证 manifest.json 格式
- 显示技能包内容列表

**优先级**: 低
