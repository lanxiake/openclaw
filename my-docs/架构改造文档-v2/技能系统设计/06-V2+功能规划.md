# V2+ 功能规划（仅设计，不实现）

## V2: 安全加密

| 功能                     | 说明                                                |
| ------------------------ | --------------------------------------------------- |
| WASM 加密传输            | AES-256-GCM 加密 + RSA 设备公钥封装 AES 密钥        |
| 设备绑定密钥             | RSA-OAEP-2048，私钥 Electron safeStorage/DPAPI 保护 |
| skill_encryption_keys 表 | 设备密钥注册、轮换、吊销                            |
| skill_download_logs 表   | 安装/更新/卸载审计日志                              |
| Electron IPC 扩展        | `electronAPI.crypto.*`, `electronAPI.wasm.*`        |
| 本地加密存储             | Electron safeStorage + AES 加密 WASM 文件           |

## V3: WASM 沙箱执行

| 功能            | 说明                                        |
| --------------- | ------------------------------------------- |
| WASM 沙箱执行器 | Node.js WebAssembly API，内存限制/超时/清零 |
| 权限隔离        | 文件系统/网络/进程 权限声明与检查           |
| 运行时监控      | 内存使用、CPU 时间、执行次数统计            |

## V4: 订阅配额

| 功能          | 说明                                         |
| ------------- | -------------------------------------------- |
| quota-service | Free 100 自定义 / Pro 1000 / Team+ 无限      |
| 订阅级别过滤  | 安装时校验用户 plan ≥ 技能 subscriptionLevel |
| 配额展示      | Windows "已安装 X/Y"，升级提示               |

## V5: 技能市场

| 功能               | 说明                            |
| ------------------ | ------------------------------- |
| 用户上传技能到商店 | 审核流程 + 版本管理             |
| 收入分成           | paymentOrders.orderType="skill" |
| 评分评论增强       | 评论审核、回复、聚合            |
| 技能版本管理       | skill_versions 表               |
| 本地开发 SDK       | 模板生成器、WASM 编译工具链     |
