# `mtbot tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/tui)

## Examples

```bash
mtbot tui
mtbot tui --url ws://127.0.0.1:18789 --token <token>
mtbot tui --session main --deliver
```
