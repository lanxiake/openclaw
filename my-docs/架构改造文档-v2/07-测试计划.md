## 3. 测试执行顺序

```
阶段 A: 后端接口测试（单元 + 集成）
├── 1. 基础工具 → 密码、JWT、ID
├── 2. 数据访问层 → 仓库（Mock DB）
├── 3. 业务服务层 → 认证、订阅、技能（Mock 仓库）
├── 4. Gateway RPC → server-methods（集成）
└── ✅ 通过标准：P0 模块测试全部通过，覆盖率 ≥ 70%

阶段 B: 前后端联调测试
├── 5. Gateway 客户端 → 连接、RPC 调用
├── 6. 前端页面 → 登录、列表、CRUD
├── 7. 前后端数据流 → 请求 → 响应 → 渲染
└── ✅ 通过标准：核心业务流程前后端打通

阶段 C: E2E 与手动测试
├── 8. 用户注册→登录→对话→技能→支付 完整流程
├── 9. Windows 桌面 Phase 1～4 手动测试
└── ✅ 通过标准：核心场景端到端通过
```
