# 订阅系统设计文档

> 最后更新：2026-02-25

## 1. 概述

OpenClaw 订阅系统提供三种订阅计划：**免费版**、**月付版**和**年付版**。订阅的核心价值是每月发放积分。所有用户共享统一的资源限制。只有管理员可以修改和取消用户订阅。

### 1.1 设计原则

- **简化套餐**：只有免费、月付和年付三种，不区分 Pro/Team/Enterprise 等层级
- **积分驱动**：订阅的核心权益是每月积分发放，而非功能解锁
- **统一限制**：资源限制对所有用户一致，不因套餐不同而区别
- **管理员控制**：订阅变更（修改/取消）仅管理员可操作

## 2. 订阅计划

### 2.1 计划定义

| 计划   | 代码      | 月价     | 年价      | 每月积分 | 说明                 |
| ------ | --------- | -------- | --------- | -------- | -------------------- |
| 免费版 | `free`    | 0 元     | 0 元      | 0        | 仅靠注册赠送和积分包 |
| 月付版 | `monthly` | 30 元/月 | —         | 2000     | 首月 3 元            |
| 年付版 | `yearly`  | —        | 300 元/年 | 2000/月  | 等效 25 元/月        |

### 2.2 首月优惠

月付版首月 3 元（原价 30 元），通过 `subscriptions.isFirstMonth` 字段标记：

- 创建月付订阅时 `isFirstMonth = true`
- 支付金额为 300 分（3 元）
- 首月结束续费时自动恢复正常价格，`isFirstMonth = false`

### 2.3 订阅积分发放规则

- **月付**：每个计费周期开始时发放 2000 积分
- **年付**：每月 1 号发放 2000 积分
- **有效期**：当月有效，按月清零
  - 月付：积分有效期 = 当前计费周期结束时间
  - 年付：积分有效期 = 当月月底
- **过期处理**：过期清理任务自动将未使用的订阅积分清零

> **实现位置**：
>
> - 积分发放：`src/assistant/credits/credit-service.ts` - `grantSubscriptionCredits()`
> - 过期清理：`src/assistant/credits/credit-service.ts` - `cleanupExpiredBatches()`

## 3. 用户资源限制

所有用户（无论免费还是付费）共享统一的资源限制：

| 资源           | 限制     | 说明               |
| -------------- | -------- | ------------------ |
| 最大绑定设备   | ≤ 5 台   | 超出需解绑已有设备 |
| 最大技能安装数 | ≤ 100 个 | 含内置和第三方技能 |
| 文件上传大小   | ≤ 50 MB  | 单文件上传限制     |

> **配额检查实现**：`src/assistant/subscription/service.ts` - `checkQuota()`
>
> **注意**：当前代码中不同套餐有不同的设备限制（Free=1, Pro=3 等），需统一改为 5

## 4. 数据库设计

### 4.1 核心表

#### plans 套餐表

初始化脚本中内置的三种套餐定义。

| 字段             | 类型        | 说明                          |
| ---------------- | ----------- | ----------------------------- |
| id               | text PK     | UUID                          |
| code             | text UNIQUE | 套餐代码：free/monthly/yearly |
| name             | text        | 套餐名称                      |
| description      | text        | 描述                          |
| price_monthly    | integer     | 月价格（分）                  |
| price_yearly     | integer     | 年价格（分）                  |
| tokens_per_month | integer     | 每月 token 额度               |
| storage_mb       | integer     | 存储空间 (MB)                 |
| max_devices      | integer     | 最大设备数                    |
| features         | jsonb       | 功能列表                      |
| is_active        | boolean     | 是否激活                      |
| sort_order       | integer     | 排序权重                      |
| created_at       | timestamptz | 创建时间                      |
| updated_at       | timestamptz | 更新时间                      |

**初始化数据**：

```sql
-- 免费版

VALUES ('free', '免费版', 0, 0, 0, 50, 5, 1);

-- 月付版
INSERT INTO plans (code, name, price_monthly, price_yearly, tokens_per_month, storage_mb, max_devices, sort_order)
VALUES ('monthly', '月付版', 3000, 0, 2000, 50, 5, 2);

-- 年付版
INSERT INTO plans (code, name, price_monthly, price_yearly, tokens_per_month, storage_mb, max_devices, sort_order)
```

## 8. 订阅生命周期

```
用户注册
    │
    ▼
  免费用户（无订阅/free 计划）
    │
    ├── 购买月付 ──→ 创建 monthly 订阅 ──→ 发放 2000 积分
    │                    │
    │                    ├── 每月自动续费 ──→ 发放 2000 积分
    │                    ├── 管理员取消 ──→ canceled
    │                    └── 逾期未付 ──→ past_due ──→ expired
    │
    └── 购买年付 ──→ 创建 yearly 订阅 ──→ 每月发放 2000 积分
                         │
                         ├── 到期自动续费 ──→ 继续每月发放
                         ├── 管理员取消 ──→ canceled
                         └── 逾期未付 ──→ expired
```

### 8.1 订阅状态流转

```
                  ┌─────────────┐
     创建订阅 ──→ │   active     │ ←── 续费成功
                  └──────┬──────┘
                         │
            ┌────────────┼────────────┐
            ▼            ▼            ▼
     ┌──────────┐  ┌──────────┐  ┌──────────┐
     │ canceled │  │ past_due │  │ trialing │
     └──────────┘  └────┬─────┘  └────┬─────┘
                        │              │
                        ▼              ▼
                  ┌──────────┐    续费/转正 → active
                  │ expired  │
                  └──────────┘
```
