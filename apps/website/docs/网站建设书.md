## 二、网站服务内容说明

### 2.1 产品定位
麦图助手（mtbot）是一款面向个人用户和企业用户的 AI 驱动的个人电脑助理软件，通过自然语言交互方式，帮助用户通过对话方式控制和管理电脑。

### 2.2 主要功能模块

#### 2.2.1 产品展示与下载（客户端软件）
- **Windows 客户端下载服务**
  - 提供 Windows 10/11 操作系统客户端软件下载
  - 支持在线下载安装包（.exe/.msix 格式）
  - 提供安装指南和使用文档
  - 版本更新通知和自动更新服务

- **产品功能介绍**
  - 自然语言控制：通过对话方式控制电脑操作
  - 文件管理：文件搜索、整理、备份等功能
  - 系统监控：CPU、内存、磁盘等系统资源监控
  - 任务自动化：自动执行预设任务和脚本

#### 2.2.2 用户服务系统
- **用户注册与登录**
  - 用户账号注册（邮箱/手机号注册）
  - 用户登录认证
  - 密码找回功能
  - 账号安全设置

- **客户端授权管理**
  - 设备绑定与管理
  - 客户端授权验证
  - 设备数量限制（免费版1台，专业版5台，企业版不限）

#### 2.2.3 技能商店系统（客户端使用）
- **技能浏览与订阅**
  - 技能分类展示（文件管理、系统工具、数据处理等）
  - 技能详情介绍（功能说明、使用方法、评分评价）
  - 技能订阅和取消订阅
  - 技能更新推送

- **技能管理**
  - 已订阅技能列表
  - 技能启用/禁用设置
  - 技能使用统计

#### 2.2.4 会员服务系统
- **套餐展示**
  - 免费版：1台设备，基础功能
  - 专业版：5台设备，全部技能，AI记忆系统
  - 企业版：私有化部署，定制服务

- **在线支付**
  - 微信支付（企业收款）
  - 支付宝（企业收款）
  - 订单查询与发票开具

#### 2.2.5 用户支持系统
- **帮助中心**
  - 产品使用文档
  - 常见问题解答
  - 操作指南和教程
  - 技能开发文档

- **客户服务**
  - 在线客服系统（工作时间响应）
  - 问题反馈表单
  - 版本更新日志

## 三、技术架构说明

### 3.1 前端技术
- **技术栈**：HTML5 + CSS3 + JavaScript
- **响应式设计**：支持桌面端和移动端浏览
- **浏览器兼容**：Chrome、Edge、Firefox、Safari 等主流浏览器

### 3.2 后端技术
- **服务器环境**：
  - 操作系统：Linux（腾讯云服务器）
  - Web 服务器：Nginx
  - 应用服务器：Node.js
  - 数据库：PostgreSQL
  
- **核心功能**：
  - RESTful API 接口服务
  - 用户认证与授权（JWT）
  - 文件存储服务（腾讯云 COS）
  - 支付接口集成（微信支付、支付宝）

### 3.3 安全机制
- **数据传输安全**：
  - HTTPS/TLS 1.3 加密传输
  - 敏感数据加密存储
  - 密码采用 bcrypt 加密

- **应用安全**：
  - 防 SQL 注入
  - 防 XSS 攻击
  - CSRF 防护
  - API 访问限流
  - 日志审计系统

### 3.4 客户端技术（Windows）
- **开发框架**：Electron + Node.js
- **安全机制**：
  - 沙箱执行环境
  - 敏感操作二次确认
  - 操作审计日志
  - TLS 加密通信

## 五、信息安全管理

### 5.1 用户隐私保护
- 严格遵守《中华人民共和国网络安全法》
- 遵守《中华人民共和国个人信息保护法》
- 制定并公示《隐私政策》
- 用户数据仅用于提供服务，不向第三方出售或分享
- 用户拥有数据查询、修改、删除的权利

### 5.2 内容审核机制
- AI 生成内容安全过滤
- 敏感词检测与拦截
- 用户上传技能代码安全审核
- 违规内容举报机制
- 7×24小时内容监控

### 5.3 应急响应机制
- 建立网络安全应急预案
- 设立专职信息安全管理人员
- 定期进行安全漏洞扫描
- 数据定期备份（每日）
- 建立故障快速恢复机制

### 5.4 日志留存
- 用户访问日志留存不少于 6 个月
- 客户端操作日志留存不少于 6 个月
- 支付订单记录留存不少于 3 年
- 配合公安机关依法调取相关记录
