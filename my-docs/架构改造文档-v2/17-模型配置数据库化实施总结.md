# 模型配置数据库化实施总结

## 概述

将模型提供商和 Agent 配置从文件迁移到数据库,支持系统级和租户级配置。

## 实施内容

### 1. 数据库表设计

#### model_providers 表
存储 AI 模型提供商配置(Anthropic、OpenAI 等)

```sql
CREATE TABLE model_providers (
  id VARCHAR(32) PRIMARY KEY,
  config_type VARCHAR(20) DEFAULT 'system' NOT NULL,  -- 'system' | 'tenant'
  user_id VARCHAR(32) REFERENCES users(id),           -- 租户 ID

  -- 提供商信息
  provider_key VARCHAR(100) NOT NULL,                 -- 唯一标识
  provider_name VARCHAR(200),                         -- 显示名称

  -- API 配置
  base_url VARCHAR(500) NOT NULL,
  api_key VARCHAR(500) NOT NULL,
  api_type VARCHAR(50) DEFAULT 'openai-completions',

  -- 模型列表
  models JSONB NOT NULL,                              -- 支持的模型列表

  -- 状态
  enabled BOOLEAN DEFAULT true,
  priority INTEGER DEFAULT 100,                       -- 优先级(越小越优先)

  -- 元数据
  created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
  created_by VARCHAR(32),
  updated_by VARCHAR(32),

  CONSTRAINT model_providers_unique UNIQUE(config_type, user_id, provider_key)
);
```

#### agent_configs 表
存储 Agent 默认配置

```sql
CREATE TABLE agent_configs (
  id VARCHAR(32) PRIMARY KEY,
  config_type VARCHAR(20) DEFAULT 'system' NOT NULL,
  user_id VARCHAR(32) REFERENCES users(id),

  -- Agent 配置
  primary_model VARCHAR(100) DEFAULT 'claude-opus-4-5-20251101',
  workspace_path VARCHAR(500),
  compaction_mode VARCHAR(50) DEFAULT 'safeguard',
  max_concurrent INTEGER DEFAULT 4,
  subagents_max_concurrent INTEGER DEFAULT 8,
  extra_config JSONB,

  -- 元数据
  created_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT now(),
  created_by VARCHAR(32),
  updated_by VARCHAR(32),

  CONSTRAINT agent_configs_system_unique UNIQUE(config_type),
  CONSTRAINT agent_configs_tenant_unique UNIQUE(user_id)
);
```

### 2. Repository 实现

#### ModelProviderRepository

1. **API Key 安全**

   - 传输时使用 HTTPS
   - 日志中不记录敏感信息

2. **配置验证**
   - 创建/更新时验证 baseUrl 格式
   - 验证 models 数组非空
   - 验证 priority 范围

3. **性能优化**
   - 配置查询添加缓存
   - 使用索引优化查询
