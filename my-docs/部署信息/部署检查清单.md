# OpenClaw 部署检查清单

本文档提供部署前后的检查清单，确保所有服务正确配置和运行。

## 部署前检查

### 服务器环境

- [ ] 操作系统版本符合要求（Ubuntu 22.04+ / CentOS 8+ / Debian 11+）
- [ ] 系统已更新到最新版本
- [ ] 已安装 Docker 20.10+
- [ ] 已安装 Docker Compose 2.0+
- [ ] 已安装 Nginx 1.20+
- [ ] 已安装 Node.js 22+（用于构建和迁移）
- [ ] 服务器有足够的资源（CPU、内存、磁盘）
- [ ] 防火墙已配置，开放必要端口
- [ ] 已创建部署目录 `/opt/mtbot`

### 配置文件

- [ ] 已复制 `docker-compose.infra.yml` 到部署目录
- [ ] 已复制 `docker-compose.prod.yml` 到部署目录
- [ ] 已创建 `.env.infra` 文件（从 `.env.infra.example`）
- [ ] 已创建 `.env.production` 文件（从 `.env.production.example`）
- [ ] **已修改所有默认密码**（PostgreSQL、Redis、MinIO 等）
- [ ] **已生成强密码**（JWT_SECRET、SESSION_SECRET 等）
- [ ] **已配置 Gateway Token**（OPENCLAW_GATEWAY_TOKEN）
- [ ] 已配置所有必需的 API 密钥（模型提供商、消息通道等）
- [ ] 已配置数据库连接字符串（DATABASE_URL）
- [ ] 已配置 Redis 连接信息
- [ ] 已配置 MinIO 连接信息

### 安全配置

- [ ] 所有密码长度至少 16 位
- [ ] 密码包含大小写字母、数字和特殊字符
- [ ] 未使用默认密码
- [ ] API 密钥已正确配置
- [ ] Gateway Token 已生成并配置
- [ ] 已配置防火墙规则
- [ ] 已计划配置 SSL/TLS 证书

## 检查命令参考

### 服务状态检查

```bash
# 检查所有容器状态
docker ps

# 检查基础设施服务
docker-compose -f docker-compose.infra.yml ps

# 检查应用服务
docker-compose -f docker-compose.prod.yml ps
```

### 健康检查

```bash
# PostgreSQL
docker-compose -f docker-compose.infra.yml exec postgres pg_isready

# Redis
docker-compose -f docker-compose.infra.yml exec redis redis-cli ping

# API Server
curl http://localhost:22300/api/health

# Gateway
curl -H "Authorization: Bearer $OPENCLAW_GATEWAY_TOKEN" http://localhost:22189/health
```

### 日志检查

```bash
# 查看所有服务日志
docker-compose -f docker-compose.prod.yml logs -f

# 查看单个服务日志
docker-compose -f docker-compose.prod.yml logs -f api-server

# 查看 Nginx 日志
sudo tail -f /var/log/nginx/error.log
```

### 资源使用检查

```bash
# Docker 容器资源使用
docker stats

# 系统资源使用
htop
# 或
top
```
