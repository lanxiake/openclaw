| 缺口                 | 位置                     | 说明                                                     |
| -------------------- | ------------------------ | -------------------------------------------------------- |
| WASM 包上传          | API Server               | 无 multipart 文件上传端点                                |

| Admin Console 编辑页 | 缺失                     | 创建弹窗有，但无独立编辑页面                             |

## 2. V1 目标（最小可用路径）

> 管理员上传技能包 → 发布 → 用户浏览 → 安装 → 使用 → 卸载

不含加密、不含 WASM 沙箱、不含设备密钥——这些推迟到 V2。

## 3. 需要做的事

### Phase 1: 服务端 — 技能包上传与下载

**文件变更：**

| 文件                                         | 操作 | 内容                                                                                                               |
| -------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------ |
| `src/db/schema/skill-store.ts`               | 修改 | 新增 `sourceType`, `wasmPackageKey`, `wasmPackageHash`, `wasmPackageSize`, `createdByAdminId`, `isSystem` 字段     |
| `src/db/schema/index.ts`                     | 修改 | 导出新类型                                                                                                         |
| `src/db/migrations/0010_xxx.sql`             | 新建 | ALTER TABLE 迁移                                                                                                   |
| `apps/api-server/src/routes/admin/skills.ts` | 修改 | 新增 `POST /api/admin/skills` (创建), `PUT /:id` (编辑), `DELETE /:id` (删除), `POST /:id/upload-package` (上传包) |
| `apps/api-server/src/routes/store/index.ts`  | 修改 | 实现 `POST /:id/install` 和 `DELETE /:id/install` 的真实逻辑; 新增 `GET /:id/download`                             |
| `src/assistant/skills/skill-service.ts`      | 修改 | 补充文件上传到 MinIO 的逻辑                                                                                        |

**Schema 新增字段（skill_store_items）：**

```typescript
sourceType: text("source_type", { enum: ["system", "user"] }).notNull().default("user"),
wasmPackageKey: text("wasm_package_key"),         // MinIO 存储键
wasmPackageHash: text("wasm_package_hash"),       // SHA-256 完整性校验
wasmPackageSize: integer("wasm_package_size"),     // 包大小(字节)
createdByAdminId: text("created_by_admin_id"),     // 创建管理员
isSystem: boolean("is_system").default(false).notNull(),  // 系统技能标记
```

**上传流程：**

```
Admin 上传 .wasm/.zip → API Server →
  1. 计算 SHA-256 哈希
  2. 存储到 MinIO (key = skills/{skillId}/{version}/{filename})
  3. 更新 skill_store_items (wasmPackageKey, wasmPackageHash, wasmPackageSize)
```

**安装流程（实现 store/index.ts 的 stub）：**

```
客户端请求 POST /api/store/skills/:id/install →
  1. 查询 skill_store_items 确认技能存在且已发布
  2. （V1 跳过配额检查，V2 加）
  3. 写入 user_installed_skills 记录
  4. 更新 downloadCount++
  5. 返回技能信息 + 下载 URL

客户端请求 GET /api/store/skills/:id/download →
  1. 验证用户已安装该技能
  2. 从 MinIO 获取包
  3. 返回二进制流
```

**卸载流程：**

```
客户端请求 DELETE /api/store/skills/:id/install →
  1. 删除 user_installed_skills 记录
  2. 返回成功
```

## 4. 不做的事（推迟到 V2+）

| 功能                                    | 推迟原因                |
| --------------------------------------- | ----------------------- |
| WASM 加密传输 (AES-256-GCM + RSA)       | 复杂度高，V1 先明文传输 |
| 设备绑定密钥 (skill_encryption_keys 表) | 依赖加密体系            |
| WASM 沙箱执行器                         | 需要单独设计安全边界    |
| 下载审计日志 (skill_download_logs 表)   | 非核心路径              |
| 订阅配额检查 (quota-service)            | V1 先不限制             |
| IPC Bridge 扩展 (crypto/wasm)           | 依赖加密和沙箱          |
| 用户自定义技能上传到商店                | V2 市场功能             |
| 技能版本管理                            | V2                      |
| 评分评论增强                            | V2                      |

## 5. 实施顺序

```
Phase 1.1: Schema 变更 + 迁移
Phase 1.2: Admin REST API (CRUD + 上传)
Phase 1.3: Store REST API (安装/卸载/下载 实现)
Phase 2.1: Admin Console 编辑页
Phase 2.2: Admin Console hooks 接通
Phase 3.1: Windows 客户端安装卸载接通
```

## 6. 验证方案

1. **DB 迁移**: `pnpm db:generate && pnpm db:migrate` 成功
2. **Admin CRUD**: admin-console 中创建技能 → 上传包 → 发布
3. **用户安装**: Windows 客户端浏览 → 安装 → 确认出现在已安装列表
4. **用户卸载**: Windows 客户端卸载 → 确认从列表移除
5. **单元测试**: 关键服务方法的 vitest 测试
