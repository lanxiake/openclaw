# Windows 客户端手动测试清单

## 测试日期: 2026-02-17

## 1. 记住账号密码功能

### 测试步骤:
1. 启动 Windows 客户端
2. 在登录页面输入账号和密码
3. 勾选"记住密码"复选框
4. 点击登录
5. 登录成功后,关闭应用
6. 重新启动应用

### 预期结果:
- ✅ 登录页面自动填充上次保存的账号
- ✅ 登录页面自动填充上次保存的密码
- ✅ "记住密码"复选框保持勾选状态

### 测试步骤(取消记住):
1. 在登录页面取消勾选"记住密码"
2. 点击登录
3. 登录成功后,关闭应用
4. 重新启动应用

### 预期结果:
- ✅ 登录页面不自动填充账号密码
- ✅ "记住密码"复选框未勾选
