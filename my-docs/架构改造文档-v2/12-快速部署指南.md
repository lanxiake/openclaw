# OpenClaw 快速部署指南

> 5 分钟快速部署 OpenClaw 到远程服务器

---

## 📦 一键部署

### 1. 克隆项目

```bash
git clone https://github.com/your-org/openclaw.git
cd openclaw
git checkout feat/ai-assistant-platform
```

### 2. 初始化环境

```bash
# 赋予执行权限
chmod +x deploy.sh

# 初始化环境（会提示编辑配置文件）
./deploy.sh init
```

### 3. 启动服务

```bash
# 启动所有服务
./deploy.sh start

# 查看服务状态
./deploy.sh status
```

### 4. 验证部署

```bash
# 健康检查
./deploy.sh health

# 访问服务
curl http://localhost:3000/health  # API Server
curl http://localhost:18789/health # Gateway
```

---

## 🔧 常用命令

```bash
./deploy.sh start    # 启动服务
./deploy.sh stop     # 停止服务
./deploy.sh restart  # 重启服务
./deploy.sh status   # 查看状态
./deploy.sh logs     # 查看日志
./deploy.sh backup   # 备份数据库
./deploy.sh update   # 更新代码
./deploy.sh health   # 健康检查
```

## 🌐 服务访问地址

| 服务          | 地址                   | 说明         |
| ------------- | ---------------------- | ------------ |
| API Server    | http://localhost:3000  | REST API     |
| Gateway       | ws://localhost:18789   | WebSocket    |
| Web Admin     | http://localhost:3001  | 管理后台     |
| MinIO Console | http://localhost:22004 | 对象存储管理 |
| pgAdmin       | http://localhost:22014 | 数据库管理   |

---

## 🔐 默认账户

### 管理员账户

- 用户名: `admin`
- 密码: 在 `.env.production` 中配置的 `ADMIN_PASSWORD`

### MinIO 控制台

- 用户名: `openclaw_minio`
- 密码: 在 `.env.production` 中配置的 `MINIO_SECRET_KEY`

### pgAdmin

- 邮箱: `admin@openclaw.ai`
- 密码: 在 `.env.production` 中配置的 `PGADMIN_PASSWORD`

---

## ⚠️ 重要提示

1. **修改默认密码**: 首次部署后，请立即修改 `.env.production` 中所有标记为 `CHANGE_ME` 的值

2. **防火墙配置**: 确保以下端口可访问
   - 3000 (API Server)
   - 18789 (Gateway)
   - 3001 (Web Admin)

3. **数据备份**: 定期备份数据库

   ```bash
   ./deploy.sh backup
   ```

4. **日志查看**: 出现问题时查看日志
   ```bash
   ./deploy.sh logs
   ```

## 🐛 故障排查

### 服务无法启动

```bash
# 查看服务状态
./deploy.sh status

# 查看日志
./deploy.sh logs

# 检查端口占用
netstat -tulpn | grep -E "3000|18789|22001|22002|22003"
```

### 数据库连接失败

```bash
# 检查 PostgreSQL 状态
docker exec openclaw-postgres pg_isready -U openclaw_admin

# 查看 PostgreSQL 日志
docker logs openclaw-postgres
```

### MinIO 上传失败

```bash
# 检查 MinIO 状态
docker exec openclaw-minio mc admin info myminio

# 验证存储桶
docker exec openclaw-minio mc ls myminio
```
