# 积分包管理设计文档

> 最后更新：2026-02-25

## 1. 概述

积分包（加油包）是一种按需购买的积分充值方式，**免费和付费用户均可购买**。积分包独立于订阅体系，购买后立即到账，有效期 3 个月。

## 2. 积分包定义

### 2.1 产品定义

| 包名   | 代码            | 价格（元） | 积分数 | 有效期 | 单价（积分/元） | 推荐 |
| ------ | --------------- | ---------- | ------ | ------ | --------------- | ---- |
| 基础包 | `pack_basic`    | 10         | 600    | 3 个月 | 60              | 否   |
| 标准包 | `pack_standard` | 20         | 1200   | 3 个月 | 60              | 是   |
| 优惠包 | `pack_premium`  | 50         | 3200   | 3 个月 | 64              | 否   |

### 2.2 推荐策略

- 标准包（20元/1200积分）标记为推荐
- 推荐标记在 Admin Console 中可配置
- 客户端展示时对推荐包高亮显示

## 3. 购买流程

```
用户选择积分包
    │
    ▼
创建支付订单 (orderType = 'credits')
    │
    ▼
选择支付方式 (微信/支付宝)
    │
    ▼
发起支付
    │
    ▼
支付回调/轮询确认
    │
    ▼
支付成功
    │
    ├── 创建积分批次 (source = 'purchase')
    ├── 更新积分账户余额
    └── 记录 earn 流水
```

### 3.1 订单创建

```typescript
// 创建积分包订单
const order = await createOrder({
  userId,
  orderType: "credits",
  amount: packPrice, // 积分包价格（分）
  paidAmount: packPrice, // 实付金额（分）
  metadata: {
    packCode: "pack_standard",
    credits: 1200,
    expiryMonths: 3,
  },
});
```

### 3.2 支付成功处理

```typescript
// 支付成功后发放积分
await creditService.grantBoosterCredits(userId, {
  amount: packCredits, // 积分数
  expiryMonths: 3, // 有效期 3 个月
  sourceId: order.orderNo, // 关联订单号
  description: `购买${packName}，获得 ${packCredits} 积分`,
});
```

> **实现位置**：
>
> - 订单创建：`src/assistant/payment/service.ts` - `createOrder()`
> - 积分发放：`src/assistant/credits/credit-service.ts` - `grantBoosterCredits()`

## 4. 数据存储

### 4.1 积分包定义存储

积分包定义建议存储在数据库中（通过 Admin Console 管理），而非硬编码：

```sql
-- 建议在 system_configs 或新建 credit_packs 表中管理
-- 方案一：使用 system_configs 表
INSERT INTO system_configs (key, value) VALUES (
  'credit_packs',
  '[
    {"code": "pack_basic", "name": "基础包", "price": 1000, "credits": 600, "expiryMonths": 3, "recommended": false, "sortOrder": 1},
    {"code": "pack_standard", "name": "标准包", "price": 2000, "credits": 1200, "expiryMonths": 3, "recommended": true, "sortOrder": 2},
    {"code": "pack_premium", "name": "优惠包", "price": 5000, "credits": 3200, "expiryMonths": 3, "recommended": false, "sortOrder": 3}
  ]'
);
```

### 4.2 订单记录

积分包购买订单存储在 `payment_orders` 表中：

- `order_type = 'credits'`
- `metadata` 中记录积分包代码、积分数、有效期

### 4.3 积分批次

购买成功后生成的积分批次：

- `source = 'purchase'`
- `source_id = 订单号`
- `expires_at = 购买时刻 + 3 个月`

## 5. Admin Console 管理

### 5.1 积分包管理功能

管理员可在「积分管理」中管理积分包：

| 操作           | 说明                                   |
| -------------- | -------------------------------------- |
| 查看积分包列表 | 显示所有积分包的定价、积分数、推荐状态 |
| 编辑积分包     | 修改价格、积分数、有效期               |
| 设置推荐       | 标记/取消推荐积分包                    |
| 启用/禁用      | 控制积分包是否可购买                   |

### 5.2 购买统计

| 统计项   | 说明                                 |
| -------- | ------------------------------------ |
| 购买数量 | 各积分包的总购买次数                 |
| 购买记录 | 按用户、时间、积分包类型查看购买历史 |
| 收入统计 | 各积分包的总收入                     |

### 5.3 管理员查看购买记录

通过 `payment_orders` 表查询：

```sql
SELECT
  po.order_no,
  u.display_name,
  u.phone,
  po.amount,
  po.paid_amount,
  po.payment_method,
  po.payment_status,
  po.metadata->>'packCode' as pack_code,
  po.metadata->>'credits' as credits,
  po.created_at,
  po.paid_at
FROM payment_orders po
LEFT JOIN users u ON po.user_id = u.id
WHERE po.order_type = 'credits'
ORDER BY po.created_at DESC;
```

> **Admin 页面位置**：`apps/admin-console/src/pages/credits/CreditsPage.tsx`

## 6. API 接口

### 6.1 用户端

| 端点                           | 方法 | 功能                   |
| ------------------------------ | ---- | ---------------------- |
| `/api/credits/packs`           | GET  | 获取可购买的积分包列表 |
| `/api/payments/orders`         | POST | 创建积分包购买订单     |
| `/api/payments/orders/:id/pay` | POST | 发起支付               |

### 6.2 管理员端

| 端点                              | 方法 | 功能           |
| --------------------------------- | ---- | -------------- |
| `/api/admin/credits/packs`        | GET  | 获取积分包配置 |
| `/api/admin/credits/packs`        | PUT  | 更新积分包配置 |
| `/api/admin/credits/packs/stats`  | GET  | 积分包购买统计 |
| `/api/admin/credits/packs/orders` | GET  | 积分包购买记录 |
