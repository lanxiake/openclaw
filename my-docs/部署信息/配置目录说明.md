# 配置目录说明

本文档说明部署信息目录下的配置目录结构和用途。

## 目录结构

```
my-docs/部署信息/
├── docker-init/                    # Docker 容器初始化配置
│   ├── postgres/                   # PostgreSQL 初始化脚本
│   │   └── 01-init.sql            # 数据库扩展和初始配置
│   ├── prometheus/                 # Prometheus 监控配置
│   │   └── prometheus.yml         # Prometheus 抓取配置
│   ├── loki/                      # Loki 日志聚合配置
│   │   └── loki-config.yml        # Loki 服务配置
│   └── grafana/                    # Grafana 仪表盘配置
│       └── provisioning/          # 自动配置
│           └── datasources/        # 数据源配置
│               └── datasources.yml # Prometheus/Loki/PostgreSQL 数据源
├── mtbot.top_nginx/                # SSL 证书目录
│   ├── mtbot.top.crt              # SSL 证书文件
│   ├── mtbot.top.key              # SSL 私钥文件
│   └── mtbot.top.csr              # 证书签名请求（可选）
└── logs/                           # 应用日志目录（运行时创建）
    ├── api-server/                # API Server 日志
    └── gateway/                   # Gateway 日志
```

## 配置说明

### docker-init/

包含所有 Docker 容器的初始化配置和脚本。

#### postgres/

PostgreSQL 数据库初始化脚本，在容器首次启动时自动执行。

**文件**: `01-init.sql`

**功能**:

- 启用 UUID 扩展 (`uuid-ossp`)
- 启用模糊搜索扩展 (`pg_trgm`)
- 启用复合索引扩展 (`btree_gin`)
- 可选：创建只读用户

**使用方式**:
在 `docker-compose.infra.yml` 中通过 volume 挂载：

```yaml
volumes:
  - ./docker-init/postgres:/docker-entrypoint-initdb.d:ro
```

#### prometheus/

Prometheus 监控服务配置。

**文件**: `prometheus.yml`

**功能**:

- 配置抓取间隔
- 配置监控目标（Prometheus 自身、PostgreSQL、Redis、MinIO、Gateway 等）
- 配置告警规则（可选）

**使用方式**:
在 `docker-compose.infra.yml` 中通过 volume 挂载：

```yaml
volumes:
  - ./docker-init/prometheus/prometheus.yml:/etc/prometheus/prometheus.yml:ro
```

#### loki/

Loki 日志聚合服务配置。

**文件**: `loki-config.yml`

**功能**:

- 配置日志存储路径
- 配置日志保留策略（默认 30 天）
- 配置压缩和清理策略

**使用方式**:
在 `docker-compose.infra.yml` 中通过 volume 挂载：

```yaml
volumes:
  - ./docker-init/loki/loki-config.yml:/etc/loki/local-config.yaml:ro
```

#### grafana/

Grafana 仪表盘自动配置。

**文件**: `provisioning/datasources/datasources.yml`

**功能**:

- 自动配置 Prometheus 数据源
- 自动配置 Loki 数据源（日志）
- 自动配置 PostgreSQL 数据源

**使用方式**:
在 `docker-compose.infra.yml` 中通过 volume 挂载：

```yaml
volumes:
  - ./docker-init/grafana/provisioning:/etc/grafana/provisioning:ro
```

### mtbot.top_nginx/

SSL/TLS 证书文件目录。

**文件**:

- `mtbot.top.crt` - SSL 证书文件
- `mtbot.top.key` - SSL 私钥文件（**必须保密**）
- `mtbot.top.csr` - 证书签名请求（可选，用于证书续期）

**部署到服务器**:

```bash
# 复制证书到服务器
sudo mkdir -p /opt/mtbot/mtbot.top_nginx
sudo cp -r mtbot.top_nginx/* /opt/mtbot/mtbot.top_nginx/

# 设置权限（确保私钥安全）
sudo chmod 600 /opt/mtbot/mtbot.top_nginx/*.key
sudo chmod 644 /opt/mtbot/mtbot.top_nginx/*.crt
```

**在 Nginx 中使用**:

```nginx
ssl_certificate /opt/mtbot/mtbot.top_nginx/mtbot.top.crt;
ssl_certificate_key /opt/mtbot/mtbot.top_nginx/mtbot.top.key;
```

### logs/

应用日志目录（运行时自动创建）。

**子目录**:

- `api-server/` - API Server 应用日志
- `gateway/` - Gateway 服务日志

**注意**: 此目录在首次启动服务时自动创建，无需手动创建。

## 配置更新流程

### 1. 更新数据库初始化脚本

```bash
# 编辑初始化脚本
nano docker-init/postgres/01-init.sql

# 重启 PostgreSQL 容器（会重新执行初始化）
docker-compose -f docker-compose.infra.yml restart postgres
```

**注意**: 初始化脚本只在数据库首次创建时执行。如需在已有数据库上执行，需要手动连接执行。

### 2. 更新监控配置

```bash
# 编辑 Prometheus 配置
nano docker-init/prometheus/prometheus.yml

# 重新加载 Prometheus（无需重启）
docker-compose -f docker-compose.infra.yml exec prometheus kill -HUP 1
```

### 3. 更新证书

```bash
# 备份旧证书
cp -r mtbot.top_nginx mtbot.top_nginx.backup

# 复制新证书文件
cp new-cert.crt mtbot.top_nginx/mtbot.top.crt
cp new-cert.key mtbot.top_nginx/mtbot.top.key

# 更新服务器上的证书
sudo cp mtbot.top_nginx/* /opt/mtbot/mtbot.top_nginx/

# 重新加载 Nginx
sudo nginx -t && sudo systemctl reload nginx
```

## 安全注意事项

1. **私钥文件**: `mtbot.top.key` 必须保密，不要提交到版本控制系统
2. **文件权限**: 私钥文件权限应设置为 `600`（仅所有者可读写）
3. **备份**: 定期备份配置文件和证书
4. **版本控制**: 初始化脚本可以提交到版本控制，但证书文件不应提交
