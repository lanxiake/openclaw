# Phase 1: 数据库 Schema 变更详细设计

## 1. skill_store_items 表新增字段

在 `src/db/schema/skill-store.ts` 的 `skillStoreItems` 表中新增 6 个字段：

```typescript
// ---- V1 新增字段 ----

/** 技能来源类型: system=系统技能(管理员创建), user=用户上传 */
sourceType: text("source_type", {
  enum: ["system", "user"],
}).notNull().default("user"),

/** 包在 MinIO 中的存储键 (如 skills/{id}/{version}/package.wasm) */
wasmPackageKey: text("wasm_package_key"),

/** 包 SHA-256 哈希 (完整性校验) */
wasmPackageHash: text("wasm_package_hash"),

/** 包大小 (字节) */
wasmPackageSize: integer("wasm_package_size"),

/** 创建此技能的管理员 ID (仅系统技能有值) */
createdByAdminId: text("created_by_admin_id")
  .references(() => admins.id, { onDelete: "set null" }),

/** 是否系统技能 (快速过滤) */
isSystem: boolean("is_system").default(false).notNull(),
```

新增索引：

```typescript
index("skill_store_items_source_type_idx").on(table.sourceType),
index("skill_store_items_is_system_idx").on(table.isSystem),
```

新增关系：

```typescript
// skillStoreItemsRelations 中新增:
createdByAdmin: one(admins, {
  fields: [skillStoreItems.createdByAdminId],
  references: [admins.id],
  relationName: "createdByAdmin",
}),
```

## 2. 迁移 SQL

文件: `src/db/migrations/0010_skill_system_v1.sql`

```sql

ALTER TABLE "skill_store_items" ADD COLUMN "source_type" text NOT NULL DEFAULT 'user';
ALTER TABLE "skill_store_items" ADD COLUMN "wasm_package_key" text;
ALTER TABLE "skill_store_items" ADD COLUMN "wasm_package_hash" text;
ALTER TABLE "skill_store_items" ADD COLUMN "wasm_package_size" integer;
ALTER TABLE "skill_store_items" ADD COLUMN "created_by_admin_id" text REFERENCES "admins"("id") ON DELETE SET NULL;
ALTER TABLE "skill_store_items" ADD COLUMN "is_system" boolean NOT NULL DEFAULT false;

-- 新索引
CREATE INDEX "skill_store_items_source_type_idx" ON "skill_store_items" ("source_type");
CREATE INDEX "skill_store_items_is_system_idx" ON "skill_store_items" ("is_system");
```

## 3. 类型更新

在 `src/db/schema/skill-store.ts` 底部补充类型导出：

```typescript
/** 技能来源类型 */
export type SkillSourceType = "system" | "user";
```

在 `src/db/schema/index.ts` 中导出新类型：

```typescript
export type { SkillSourceType } from "./skill-store.js";
```

## 4. Zod Schema 更新

已有的 `createInsertSchema(skillStoreItems)` 和 `createSelectSchema(skillStoreItems)` 会自动包含新字段，无需手动修改。

## 5. 注意事项

- 迁移使用 `pnpm db:generate` 自动生成，手写 SQL 仅作参考
- `createdByAdminId` 使用 `SET NULL` 外键，管理员被删除时不影响技能记录
- `sourceType` 默认为 `"user"` 保持向后兼容，现有数据不受影响
- `isSystem` 默认为 `false`，与 `sourceType="system"` 冗余但便于快速过滤查询
