## 开发约定 📝

### 代码风格

- **不可变性**: 始终创建新对象，不修改原对象
- **文件大小**: 200-400 行，最大 800 行
- **错误处理**: 必须完全处理异常
- **输入验证**: 使用 zod 验证用户输入

### Git 工作流

- **提交消息格式**: `<type>(<scope>): <description>`
- **分模块提交**: 跨子系统变更必须按模块拆分
- **提交前步骤**:
  1. 手动执行 `pnpm format:fix` 完成格式化
  2. 使用 `--no-verify` 跳过 hook（Windows 兼容性问题）
  3. 恢复无关文件变更

### TDD 原则

1. 编写测试 (RED)
2. 运行测试 - 应该失败
3. 编写最小实现 (GREEN)
4. 运行测试 - 应该通过
5. 重构 (IMPROVE)
6. 验证覆盖率 (80%+)

### Agent 使用

- **planner**: 复杂功能规划
- **tdd-guide**: 新功能/bug 修复
- **code-reviewer**: 代码审查
- **security-reviewer**: 安全审核
- **build-error-resolver**: 构建错误修复
- **e2e-runner**: E2E 测试

## 技术栈 🛠️

- **语言**: TypeScript (ESM, 严格模式, ES2023 目标)
- **运行时**: Node.js >= 22.12.0
- **包管理**: pnpm 10.23.0
- **构建**: tsc + rolldown
- **检查**: oxlint (type-aware) + oxfmt
- **测试**: Vitest 4 (V8 覆盖率)
- **数据库**: PostgreSQL + Drizzle ORM
- **CLI**: Commander.js 14
- **HTTP**: Express 5
- **WebSocket**: ws 8
- **Agent**: Pi RPC agent

## 系统架构 🏗️

### 核心数据流

```
消息通道 (WhatsApp/Telegram/Slack/Discord/Signal/iMessage/Teams)
    ↓
┌─────────────────────────────────┐
│  Gateway (ws://localhost:18789) │
│  ├─ 路由                        │
│  ├─ Pi Agent RPC               │
│  ├─ Sessions                   │
│  └─ Tools                      │
└─────────────────────────────────┘
    ├─ CLI
    ├─ WebChat UI
    ├─ macOS 菜单栏应用
    └─ iOS / Android 节点
```

### 主要子系统

| 目录            | 功能                                                        |
| --------------- | ----------------------------------------------------------- |
| `src/gateway/`  | WebSocket 服务器、HTTP 服务器、协议方法、认证、桥接         |
| `src/agents/`   | Pi RPC Agent 运行时、工具执行、认证配置文件、模型认证、沙箱 |
| `src/routing/`  | 入站消息路由、会话密钥派生、允许列表匹配                    |
| `src/db/`       | PostgreSQL (Drizzle ORM) - Schema、仓库、迁移、连接池       |
| `src/channels/` | 共享通道逻辑                                                |
| `src/cli/`      | Commander.js CLI 接线                                       |
| `src/commands/` | CLI 命令实现                                                |
| `src/media/`    | 图像/音频/视频 管道、转录                                   |
| `src/browser/`  | Chrome 自动化 (CDP)                                         |
| `src/security/` | 沙箱、工具审批                                              |
