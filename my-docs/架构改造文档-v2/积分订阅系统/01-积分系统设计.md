# 积分系统设计文档

> 最后更新：2026-02-25

## 1. 概述

MtBot 采用**积分制**作为核心计费模型，替代传统的套餐分层制。所有用户（免费和付费）统一通过积分消费大模型调用。积分按批次管理，每个批次有独立过期时间，消费时采用 **FIFO（先到期先消费）** 策略。

### 1.1 核心原则

- **统一货币**：积分是唯一的计费单位，所有大模型调用均通过积分结算
- **批次隔离**：每次获得的积分是独立批次，各有独立过期时间
- **FIFO 消费**：优先扣减快到期的积分批次
- **不可篡改**：积分流水为只读审计日志，不可修改

## 3. 积分消费

### 3.1 消费场景

当前唯一消费场景为**大模型调用**。

### 3.2 计费公式

```
积分消耗 = ceil((input_tokens × input_price + output_tokens × output_price) / 1,000,000 × multiplier)
```

- `input_price`：每百万 input tokens 消耗的积分数
- `output_price`：每百万 output tokens 消耗的积分数
- `multiplier`：管理员倍率调节（默认 1.00，精度 5 位整数 2 位小数）
- 最少消耗 1 积分

> **实现位置**：`src/assistant/credits/credit-service.ts` - `calculateModelCallCost()`

### 3.3 FIFO 消费流程

```
1. 验证消费金额 > 0
2. 获取用户积分账户
3. 检查余额 >= 消费金额
4. 获取有效批次列表（按 expires_at ASC 排序）
5. 逐批扣减：
   a. 从最快过期的批次开始
   b. deduct = min(remaining, batch.remainingAmount)
   c. 更新 batch.remainingAmount
   d. remaining -= deduct
6. 更新账户余额（totalBalance -= amount, totalConsumed += amount）
7. 记录 consume 类型流水
```

> **实现位置**：`src/assistant/credits/credit-service.ts` - `consumeCredits()`

### 3.4 消费流水元数据

每笔模型调用消费的流水会记录以下元数据：

```typescript
interface CreditTransactionMetadata {
  modelId?: string; // 模型标识
  inputTokens?: number; // 输入 token 数
  outputTokens?: number; // 输出 token 数
  inputPrice?: number; // 输入单价
  outputPrice?: number; // 输出单价
  multiplier?: number; // 应用的倍率
  adminId?: string; // 管理员操作时的 ID
  adminNote?: string; // 管理员备注
}
```

## 4. 过期清理

定时任务执行过期批次清理：

```
1. 查询所有 expires_at < NOW() 且 remaining_amount > 0 的批次
2. 按用户分组处理
3. 每个过期批次：remaining_amount → 0
4. 更新用户账户：totalBalance -= expired, totalExpired += expired
5. 记录 expire 类型流水
```

> **实现位置**：`src/assistant/credits/credit-service.ts` - `cleanupExpiredBatches()`

## 5. 数据库设计

### 5.1 ER 关系图

```
users (1) ──→ (1) credit_accounts
users (1) ──→ (N) credit_batches
users (1) ──→ (N) credit_transactions
users (1) ──→ (N) invite_records (as inviter)
users (1) ──→ (1) invite_records (as invitee)
credit_batches (1) ──→ (N) credit_transactions
model_pricing (独立表，无用户关联)
```

### 5.2 表结构

#### credit_accounts 积分账户表

每用户一条记录，记录积分余额汇总。

| 字段           | 类型           | 说明           |
| -------------- | -------------- | -------------- |
| id             | text PK        | UUID           |
| user_id        | text FK UNIQUE | 用户 ID        |
| total_balance  | integer        | 当前可用总积分 |
| total_earned   | integer        | 历史总获得积分 |
| total_consumed | integer        | 历史总消费积分 |
| total_expired  | integer        | 历史总过期积分 |
| created_at     | timestamptz    | 创建时间       |
| updated_at     | timestamptz    | 更新时间       |

#### credit_batches 积分批次表

每次积分获得为一个独立批次。

| 字段             | 类型        | 说明                                                    |
| ---------------- | ----------- | ------------------------------------------------------- |
| id               | text PK     | UUID                                                    |
| user_id          | text FK     | 用户 ID                                                 |
| source           | text enum   | 来源：register/invite/subscription/purchase/admin_grant |
| original_amount  | integer     | 原始积分数                                              |
| remaining_amount | integer     | 剩余积分数                                              |
| expires_at       | timestamptz | 过期时间                                                |
| source_id        | text        | 关联来源 ID（订单号/邀请记录 ID）                       |
| description      | text        | 描述                                                    |
| created_at       | timestamptz | 创建时间                                                |

**索引**：

- `(user_id, expires_at)` — FIFO 消费查询
- `(user_id, source)` — 按来源查询
- `(expires_at)` — 过期清理

#### credit_transactions 积分流水表

不可变的审计日志。

| 字段          | 类型        | 说明                                                                                     |
| ------------- | ----------- | ---------------------------------------------------------------------------------------- |
| id            | text PK     | UUID                                                                                     |
| user_id       | text FK     | 用户 ID                                                                                  |
| batch_id      | text FK     | 关联批次 ID                                                                              |
| type          | text enum   | 类型：earn/consume/expire/refund/admin_adjust                                            |
| amount        | integer     | 变动量（正数获得，负数消费/过期）                                                        |
| balance_after | integer     | 变动后余额                                                                               |
| source        | text enum   | 来源：register/invite/subscription/purchase/model_call/admin_grant/expiry_cleanup/refund |
| source_id     | text        | 关联来源 ID                                                                              |
| description   | text        | 描述                                                                                     |
| metadata      | jsonb       | 扩展信息                                                                                 |
| created_at    | timestamptz | 创建时间                                                                                 |

**索引**：

- `(user_id, created_at)` — 用户流水时间线
- `(user_id, type)` — 按类型查询
- `(source, source_id)` — 按来源追溯

#### invite_records 邀请记录表

| 字段            | 类型           | 说明                    |
| --------------- | -------------- | ----------------------- |
| id              | text PK        | UUID                    |
| inviter_user_id | text FK        | 邀请人                  |
| invitee_user_id | text FK UNIQUE | 被邀请人（唯一）        |
| credits_awarded | integer        | 奖励积分数              |
| status          | text enum      | 状态：completed/revoked |
| created_at      | timestamptz    | 创建时间                |

#### model_pricing 模型定价表

| 字段         | 类型         | 说明                                                |
| ------------ | ------------ | --------------------------------------------------- |
| id           | text PK      | UUID                                                |
| model_id     | text UNIQUE  | 模型标识（如 "anthropic/claude-sonnet-4-20250514"） |
| model_name   | text         | 模型显示名称                                        |
| input_price  | integer      | 每百万 input tokens 积分消耗                        |
| output_price | integer      | 每百万 output tokens 积分消耗                       |
| multiplier   | numeric(5,2) | 管理员倍率调节（默认 1.00）                         |
| is_active    | boolean      | 是否激活                                            |
| created_at   | timestamptz  | 创建时间                                            |
| updated_at   | timestamptz  | 更新时间                                            |

## 8. 模型定价管理（Admin Console）

### 8.1 功能概述

管理员通过 Admin Console 的「积分管理 → 模型定价管理」页面配置每个模型的积分消耗规则。

### 8.2 操作流程

1. 系统自动获取已录入的模型提供商列表
2. 管理员从下拉列表选择模型
3. 设置 input token 积分单价（每百万 tokens）
4. 设置 output token 积分单价（每百万 tokens）
5. 设置倍率（multiplier），便于批量调整 token 与积分的比例
6. 保存生效

### 8.3 倍率机制

倍率是一个全局乘数，应用于最终计算结果：

```
实际消耗 = 基础消耗 × multiplier
```

用途：

- **促销活动**：设置 multiplier < 1.0，降低消耗（如半价活动 multiplier = 0.5）
- **成本调整**：设置 multiplier > 1.0，提高消耗
- **默认值**：1.00（不调整）

> **Admin 页面位置**：`apps/admin-console/src/pages/credits/PricingPage.tsx`
